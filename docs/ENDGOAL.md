# WILLIAMOS - PRODUCT FOUNDATION

## What is WilliamOS?

WilliamOS is a Personal AI Assistant.

Not a chatbot.
Not a task manager.
Not a dashboard.

WilliamOS should function like a personal Chief of Staff.

Its purpose is to help users:

- stay organized
- prioritize correctly
- make better decisions
- reduce mental load
- remember important things
- understand their progress over time

Core question:

"What should I focus on right now?"

---

# The Core Problem

Most people have information spread across:

- Outlook
- Calendars
- Notes
- Documents
- Banks
- Insurance providers
- Task managers
- Health apps
- Their own memory

This creates:

"I feel like I am forgetting something."

WilliamOS exists to solve that problem.

# Product Rule #1

WilliamOS should not only provide advice.

WilliamOS should propose actions.

Bad:

"You should create a task."

Good:

"I found a possible task:

Mazda reinspection before 18.10.2026

[Create Task]"

# Product Rule #2
